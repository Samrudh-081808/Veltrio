# Veltrio Icon Pack

A consistent 32-icon family for Veltrio. Each SVG is an independent transparent 24×24 vector asset with rounded 1.8-unit strokes. Teal assets use `#168F80`; `_charcoal` variants use `#1F2421`.

Use the teal version by default and the charcoal counterpart where a neutral foreground better fits the control. SVG files can be loaded directly by Qt's `QIcon` when the SVG Qt module is available.

Icons: Dashboard, Tasks, Calendar, Notes, Inbox, Work, Study, Health, Holiday Trip, Workspace, Search, Export Summary, Theme, Notifications, Profile, Add Task, Complete Task, Edit, Delete, More Options, Date/Deadline, List Selector, Timer Start, Timer Pause, Timer Reset, Increase Time, Decrease Time, Focus, Settings, Close, Previous, Next.
